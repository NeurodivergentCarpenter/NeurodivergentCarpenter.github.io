# NeurodivergentCarpenter.github.io
The average building and construction company in New Zealand is very small, with roughly 91% of construction firms employing between 0 and 5 people (including sole traders and working directors).

I am thinking about pursuing the administrative side of residential building and  an using this website as a mind map of the various tasks associated with learning about it.

I want to create a service targeted to smaller firms to take care of administrative tasks that can be done remotely.

It is a documentation of the learning process and the experimentation of ideas. 

Just basic ideas, like:

* digitising site paperwork
  * timesheets
  * health and safety compliance
* photographic uploading
* Checklists
* Automating typing tasks
